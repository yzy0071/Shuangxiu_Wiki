# 双休优选（getshuangxiu.com）Wiki

双休优选是一个只收集“周末双休”岗位的招聘信息站。它每天从公开招聘信息中收集岗位，用一套固定规则推算每个岗位是否真的双休，并且只展示能找到投递入口的岗位。

- 线上地址：<https://getshuangxiu.com>
- 技术栈：Node.js 24、内置 `node:sqlite`、原生前端（无框架）、Docker Compose 单服务、GitHub Actions

本仓库只放说明文档。站点代码不公开。

## 一分钟了解

1. **收集**：每天从公开的招聘平台、地方人才网、企业官网、政府公开数据和企业官方招聘系统收集岗位。
2. **归并**：同一岗位在多个来源出现时合并成一条，保留各来源记录。
3. **推算双休**：按固定规则给出 6 个等级之一（可能性高 / 偏向双休 / 无法判断 / 存疑 / 大概率非双休 / 说法冲突）。这是规则算法，不是大模型，每一分都能追溯到具体原因。
4. **展示**：只展示覆盖城市内、有投递入口的岗位；界面上的“推算：…”标签明确注明不是核实结论。

## 项目遵守的边界

- 只读取不登录就能看到的公开页面；不登录、不请求验证码、不伪造令牌、不绕过证书或安全校验。
- 遇到验证码、拒绝访问或限流立即停止。
- 不代用户投递简历；用户始终在雇主或招聘平台自己的页面上投递。
- 双休推算结果是估计，界面上始终与人工核实的结论分开标注。
